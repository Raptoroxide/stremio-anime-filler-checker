# Credits, sources and licences

This add-on is an informational companion. It does not host or redistribute video content. All episode classifications belong to their sources, are community-maintained, and can be corrected at the source at any time. Every result links back to the exact source page.

## AnimeFillerList — primary data source

- Site: <https://www.animefillerlist.com/>
- Example page used in tests: <https://www.animefillerlist.com/shows/naruto>

How it is used:

- Episode classifications are **fetched on demand** (one show page per lookup), parsed, and cached in memory for ~24 hours. Only public episode-classification data is parsed (episode number, classification label, episode title). No article text, artwork, or other material is republished.
- The site's `robots.txt` is respected: only allowed paths (`/shows/…`) are requested, and its `Crawl-delay: 10` directive is honoured per warm instance. A descriptive User-Agent identifies the add-on. No bot protection, CAPTCHA, or access restriction is bypassed.
- `src/providers/data/afl-shows-seed.js` bundles **public show titles and URL slugs** from the shows index (routing information only, retrieved 2026-11-07, regenerable with `npm run update-data`) so that most lookups need at most one upstream request. Episode classifications themselves are never bundled.
- Not affiliated with, endorsed by, or sponsored by AnimeFillerList.

## FillerLists — bundled fallback dataset (CC BY-SA 4.0)

- Data page: <https://fillerlists.com/data>
- Licence: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Dataset coverage at bundling time: 13 long-running anime, 4,076 episodes (dataset "updated" field: 2026-11-03; bundled 2026-11-07).

Required credit (from the source dataset):

> Anime filler data from FillerLists (https://fillerlists.com/data) and its sources, under CC BY-SA 4.0.

Modifications (per the licence's requirement to note changes): the per-show JSON files were **trimmed** to episode numbers plus single-letter verdict codes and a small subset of show metadata (name, ids, urls, check dates); episode titles, air dates, arcs and TVmaze ids were dropped to keep the bundle small. **Verdict values are unchanged.** The adaptation lives in `src/providers/data/fillerlists-bundle.js` (also generated by `npm run update-data`) and is **shared under the same CC BY-SA 4.0 licence** — the file header repeats this notice.

FillerLists itself credits its own sources (TVmaze episode data, franchise wikis such as Narutopedia, Japanese Wikipedia episode lists, and AnimeFillerList); their licence notes ship with the dataset. FillerLists documents only those 13 shows — it does **not** cover anime generally, which is why AnimeFillerList remains the primary source.

## Metadata

- **Cinemeta** — Stremio's official public metadata add-on, `https://v3-cinemeta.strem.io/meta/series/{imdbId}.json`. Used to resolve IMDb ids into titles, genres, country and season/episode structures. Docs: [Stremio Add-on SDK](https://stremio.github.io/stremio-addon-sdk/advanced.html).
- **Kitsu** — public anime database JSON:API (`https://kitsu.io/api/edge/anime/{id}`), used to resolve `kitsu:` ids. No API key required.

## Protocol & tooling

- Built against the [Stremio Add-on Protocol](https://stremio.github.io/stremio-addon-sdk/protocol.html) and [SDK documentation](https://stremio.github.io/stremio-addon-sdk/) (manifest, stream object with `externalUrl`, subtitles object, CORS requirements).
- Designed for [Vercel Functions](https://vercel.com/docs/functions).

## Priority & conflicts

Provider priority is fixed and documented (see `src/providers/index.js`): **AnimeFillerList first**, FillerLists only when AnimeFillerList has no match or fails. Verdicts are never merged across sources; a lower-priority provider is never consulted when a higher-priority one already answered.
